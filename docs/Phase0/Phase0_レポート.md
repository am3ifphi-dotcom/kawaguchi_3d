## 4. 精度定義の運用ルール（本プロジェクト再掲）

- 外観 ±0.3m / 内部図面あり ±0.1m / 写真推定 ±0.5m。推定は必ず【推定】タグ。
- 施設マスターリストで「要素 / 根拠(資料p) / 寸法 / 確度(確定・推定・仮置き) / 備考」を管理。
- 写真と矛盾したら即停止・指摘。

## 7. 座標とタイルの検証（実施済み）

- plateu origin 35.8261337/139.7191328 は **z18 tile 232812/103096 の南東隅付近**。手持ちタイル `232811/103095` と `232812/103095` は学校の**真北800mではなく真北1タイル手前**を覆う。学校本体は `232812/103096` と `232813/103096` が必要。→ **Phase1で追加取得要**。
- PLATEAU bx/by は origin からのメートル。X+ 東, Y+ 北でBlenderと一致するため **そのまま X,Y に流し込める**。
- GSI DEM5m は同じIX系だが、BlenderGISが緯度経度で読み込むため**BlenderGISの座標系を EPSG:6677 に切替**が必要。

## 8. 情報収集の継続方針

- Waybackで `新市立高等学校基本設計について（2014.6.4）` と `実施設計等について（2015.9.1）` の原本PDFを再発掘 → 既に27901は後者と同一と推定だが、基本設計側に追加俯瞰・模型写真がある可能性。
- JIA掲載誌「近代建築2019.7」を図書館で閲覧 → 断面詳細・矩計が得られれば窓高さ確定。
- 学校公式の竣工写真11+3枚は**画面キャプチャではなく直接画像を保存禁止**のため、Blender内ではfSpyで「参照のみ」で合わせる。

## 9. 次フェーズへの申し送り

Phase 1 では:
1. BlenderGISで GSI 地理院タイル（標準地図・空中写真）+ DEM5m を IX系で読み込み
2. plateau_53395597.json をプロットし、半径300mでクリップ
3. 敷地境界（27901p03トレース）をカーブで作成し、竪川・道路を分離
4. 全体を 00_Ref に退避し、Phase2用に原点を保持
