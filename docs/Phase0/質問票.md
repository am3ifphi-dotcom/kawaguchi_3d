# 質問票（Phase 0 回答依頼）

> 回答は分かる範囲でOK。不明は「不明」で返してください。推定で進めます。

## Q1. 現地に行けるか／写真の提供可否【最重要】

- [ ] 現地へ行ける（敷地外周のみ / 敷地内許可あり）
- [ ] 既に撮影済みの外観写真がある → **枚数と撮影方向（例: 東門から校舎全景10枚）** を教えてください
- [ ] 学校公式の竣工写真以外に、説明会で配られた平面図・パンフレットを持っているか

**なぜ聞くか**: fSpyは写真1枚あたりの精度が±0.3mを左右する。ユーザ写真があればPhase3の外装再現が一気に確定する。

---

## Q2. Blender環境とPCスペック

- Blenderバージョン: ____（例: 4.1.0）
- OS: Win / Mac / Linux
- BlenderGISインストール済みか: Yes / No
- PCメモリ: ____GB / GPU: ____
- 60fpsウォークスルーが必要か、静止画レンダ重視か

**なぜ聞くか**: 3070棟PLATEAUを全読み込みすると重い。半径300mでクリップするか遠景LODを分けるかを決めるため。

---

## Q3. 再現範囲の優先順位

以下のうち、**最もこだわりたい順に1-3位**を付けてください。

- [ ] 外観（遠景で見た校舎・アリーナの正確さ）
- [ ] ラーニングストリート（膜屋根の吹抜空間）
- [ ] 大ホール（500席の椅子並び）
- [ ] 食堂・図書室・普通教室などの内部
- [ ] グラウンド・テニスコート・植栽などの外構

**なぜ聞くか**: 全てを同時進行すると時間がかかる。優先順位に沿ってPhase2→3→4の順序を調整する。

---

## Q4. 内部の利用イメージ

- ウォークスルーは「一人称で歩く」想定だが、VR（Quest等）での利用予定はあるか: Yes / No
- Godot / Unreal への書き出しは必要か: 不要 / Godot / Unreal / 未定
- 視点高は1.6m（成人）でよいか、1.5m（高校生）にするか

---

## Q5. 素材の再配布可否と出典表記

- 本モデルを外部公開（例: Sketchfab / WebGL）する予定はあるか: Yes（出典表記する） / No（個人利用のみ）
- PLATEAU・地理院の出典表記は了承済みか: Yes / 要説明

## 任意（あれば精度が上がる）

- 卒業生/在校生か、訪問者の立場か（「違和感がない」基準の解像度が違うため）
- 気になっている場所（例: 昇降口の位置、職員室前の廊下幅、食堂の混雑時の動線など）を自由記述で
