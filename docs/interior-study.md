# Phase 3：内装・ラーニングストリートの資料照合と一部試作

**内装全域の竣工再現ではない。現時点で「完全」と表示しない。** `main` 由来の `27901siryou.pdf`（2015実施設計、転載不可）pp.4–7 の室用途と p.9 の計画床レベルを先に読んだ。設計室用途と現況の設備・家具を同一視しない。`data/interior-program.json` は全階の照合対象と造形済み／未造形を別欄で記録した。

## 実画素で確認した資料

- [川口市 平成29年度竣工・校舎棟](https://www.city.kawaguchi.lg.jp/soshiki/01120/050/2/46354.html) の `ra-ninngusutori-to1.jpg`：暗色のラーニングストリート床と白い区画線、角型の植栽兼腰掛け、樹木、彩色の小型腰掛け、白い壁・コンクリート・色付き突出部・上部の膜面／渡り廊下。検索キャッシュから実画像の画素を確認した。正面画像 `ra-ninngusutori-to2.jpg` も目視。**撮影位置が未校正のため階段の位置確定には使わない。**
- 同市の `daiho-ru.jpg`：1F大ホールを写す実画素を確認。階段状の濃色固定席、木質舞台、舞台まわりの暗幕、明るい天井と側壁が見える。[学校公式案内](https://kawaguchicity-hs.ed.jp/about/facility/building) の500席と併せて部位を同定。ただし列割・実際の断面高さと2F床の開口は未確定。
- 同市の `kyousitu2.jpg`：淡色の床、木目の個別机、灰青色の椅子、長い濃色黒板、その両脇の赤い壁、細い天井照明と前方の投影機を実画素で確認。座席の実数・教室の棟と階はこの画像単独から分からない。
- [学校・校舎施設案内](https://kawaguchicity-hs.ed.jp/about/facility/building)：S棟ホームルーム、N棟特別教室、2Fラーニングストリート・食堂・カフェテリア・ラーニングコモンズ、教室向かいのロッカーとプロジェクター機能などを確認。同ページの食堂・図書室の元画像は、この環境からの直接TLS取得が失敗し、**画素未確認**。用途の根拠には使うが、家具の色や実数の根拠にはしない。
- [久米設計の解説](https://www.kumesekkei.co.jp/project/0276.html)：通りはS棟とN棟の間の半屋外空間。県産ヒノキ、川口の鋳物と植木が学校内の*様々な場所*に使われたとの説明は、具体的にどの家具がその素材かを指定する資料ではない。現行の木目材を「実際のヒノキ製品」と断定しない。

MEXTの検索結果には屋内視察資料の記述（ゴムシート床・ストリートファニチャー等）が現れたが、原文PDFは現在404で**原文を確認できなかったため内装仕上げの確定根拠として採用しない**。

## 実装した選択的な室内比較

`src/world/interior.ts` を「内装・共用部スタディ」レイヤーとして追加。2F（モデルy=4.0m）通りの白い床線、写真で確認した**型**の角型植栽座席と彩色小家具を作り、通りの大筋は遮らない。植栽3組の個数／位置は展示用。北翼2Fのラーニングコモンズに棚4本・卓3台、南翼2Fの食堂に卓8台を配置したが、これらは**用途と設計図の位置を示す家具例**であって現況の什器照合を終えたものではない。室間仕切り、厨房・売店、共用階段は未造形。

S棟3Fは一室だけの教室サンプル（モデルy=7.6m）。写真の意匠を参照した黒板、木目の机16組・灰青色椅子、赤い側帯、天井ライン照明・投影機を表示。学校写真がその設計図上の教室・階を写したとの同定はできていない。表示室のx=67.5–75.3m・北19.3–27.2m、16組・間仕切り厚・机ピッチ・素材種・実GLはすべて仮置き。**扉、避難経路、屋内歩行の衝突処理を検証したわけではない。**

比較視点「2F通り内部」「S棟3F 教室試作」を追加。OrbitControlsの最短距離が従来25mだったため教室視点を室外へ押し戻す不具合を発見し、この視点だけ0.6mに変更。Chromiumで両視点を再撮影し、通り・教室の実描画を目視した。`npm run audit`ではGIF/写真寸法ではなく、GIS候補輪郭内への代表配置、床レベルと展示用メッシュ個数だけを機械検査する。

## 重要な未確定・追加調査

1. 1F大ホール（学校の案内は500席）は仮客席を一度試したが、現行の単純な2F床スラブが客席の後方席に干渉し、頭上が約0.6mしか残らなかった。**写真とモデルの明確な矛盾**としてホール造形を撤回。吹抜け境界と縦断面が分かるまで再開しない。職員エリア、全ての教室と専科室、2F図書室・食堂の正式な間仕切りや入口は未実装。設計PDFは用途配置を示すが、竣工状態の建具・家具図、教室別寸法、仕上げ表はない。
2. 西側の正面直結階段の輪郭は依然として**現地実測で照合していない**。新たに見た市のラーニングストリート正面写真だけでは段全体の方位と接続を確定できず、別階段写真の特徴を転用しない。
3. 壁材、天井設備、書架寸法、植栽樹種、床の実際のゴムシートの範囲・色は未確定。教材用の室外からの撮影と、屋内避難・アクセシビリティの運用を混同しない。
4. 写真・PDFの実画像は権利確認なしにアプリへ配布しない。ここでの3Dはオリジナルの単純造形であり、別学校の写真やGoogle Earthメッシュの転用はしない。

次は学校公式の食堂・図書館・ロッカー・ホール竣工画像の**実画素**と、屋内竣工間仕切図／家具表・仕上表を自分でさらに探し、確定した空間から段階的に入れ替える。現行ビューから全室内を安全に歩ける、という説明はしない。
