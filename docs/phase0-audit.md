# Phase 0 入力監査・調査記録（2026-09-27）

## 調査範囲と重要な制約

- 手元の **2 PDF 全10ページのテキスト抽出とページ描画確認**、JSON全3,070要素の機械検査、2タイルの画像・ヘッダ・範囲確認を実施。PDF図中の判読は公開資料に記された計画当時の寸法であり、竣工実測の保証ではない。
- 学校公式の[施設概要](https://kawaguchicity-hs.ed.jp/about/facility)から直接参照される[校舎棟](https://kawaguchicity-hs.ed.jp/about/facility/building)、[アリーナ棟](https://kawaguchicity-hs.ed.jp/about/facility/arena)、[グラウンド](https://kawaguchicity-hs.ed.jp/about/facility/ground)、4写真アルバムの**公開HTMLテキストと画像参照**を列挙した。サイト全域へのナビゲーション（制服・学校ブログ等）は施設画像監査の範囲外。関連する[学校アクセス](https://kawaguchicity-hs.ed.jp/about/access)も住所確認。
- **公式サイトの画像ファイル本体は現環境から取得・個別画素確認できなかった**（ページテキストとキャプションは取得可）。したがって画像を「すべて目視精査済み」とは主張しない。アルバムは順番と表題まで棚卸し。学校写真をモデルの寸法根拠にしていない。ユーザーが原寸画像を提供できれば全点を再点検する。
- `27901siryou.pdf` 1ページに「川口市に了解なしの無断転用、転載を禁じます」。抽出図版や学校写真をアプリに同梱・再配布しない。撮影者・地理院・PLATEAUの各利用条件も別途確認。

## 提供GIS JSONの全要素機械監査

- `plateau_53395597.json`：トップレベル `origin`, `note`, `count`, `features`。`count=3,070`と配列3,070件一致、ID重複0、全件 `kind=bldg`、レコードは `id,h,ring`。**道路/歩道/敷地界/DEM/植栽は含まない**。提供注記は「PLATEAU LOD1抽出」「bx東/by北」「平面5m級」だが、元CityGML版・取得日・測地系・高さ定義と精度値の出典は未添付。注記を公式精度保証と見なさない。
- 相対平面範囲：東西x −612.16～+557.01m、南北y −132.41～+699.97m（3,070件すべてが「原点から300m以内」ではない）。頂点が半径300m以内の建物は**526件**（境界と交差して頂点を含まないものはこの件数に入らない）。
- 高さ `h=-9999`（欠測値）は208件。残る数値の高さレンジ3.0～49.6mだが**GL上の高さ/絶対標高等は未確認**。リング始終点が異なる4件、面積ゼロ19件、自己交差5件（うち2件は始終点不一致と重複）。**不正輪郭のユニーク件数は26件**。自己交差は北方の約695～700m帯で、今回の300m表示範囲外。欠測高さや不正輪郭から建物を押し出さない。
- 同じ `id` が外部版のどの建物に対応するか未検証。敷地内の校舎と周辺が混在する可能性があり、LOD1建物と将来の精密校舎を重複表示しない方針。

## 提供タイル・座標

- `z18_232811_103095.png` / `z18_232812_103095.png`：**ファイル名はPNGだが中身はJPEG/JFIF、どちらも256×256 px**。ブラウザの配信MIMEが拡張子と食い違うためリネーム/トランスコードは元画像の利用許諾確認後に行う。
- Slippy Map z18 範囲：緯度 **35.82672127～35.82783472°N**、経度 **139.71725464～139.72000122°E**（2枚連結）。JSON原点 `(35.8261337,139.7191328)` はこの範囲の**南に約65m**で、原点も敷地南側も覆わない。画像の出典、撮影年、権利、タイル系（Web Mercatorか）は未確認。
- 暫定座標提案：将来の水平GIS入力を **JGD2011 平面直角IX系 EPSG:6677** に正規化し（投影ライブラリは `always_xy` 指定で経度・緯度入力と東距・北距出力を固定）、確定標点 `(E0,N0)` を減じる。Three.js `(x,y,z)=(E−E0, H−H0, −(N−N0))`、1 unit=1m。原点は当面 JSON `(35.8261337,139.7191328)` に仮結び、**測量点名/GL標高・測地系は未確定**。経緯度に111km/度を一律乗じない。Web Mercatorのメートルを無補正で建築寸法に流用しない。図面との標点対応・画像ピクセルの検証が完了するまで三者の重ね合わせを禁止。
