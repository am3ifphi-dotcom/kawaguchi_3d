# Phase 1 敷地レポート — 半径300mの地形・道路・敷地境界

> 作成日: 2026-09-28 / Phase0継続
> 基準: 平面直角IX 原点 `35.8261337,139.7191328` (校舎LS中央と仮置き、03でY+12m補正)

## 1. 今回のフェーズと目的

**Phase 1 敷地** — BlenderGIS等でDEM・空中写真・道路・敷地境界を実座標で読み込み、基準原点とグリッドを設定する。後のボリューム配置の土台を作る。

## 2. 手順（継続のblendで実行）

### 2-1. 追加GSIタイル取得（手動）

サンドボックスからは `cyberjapandata.gsi.go.jp` へのSSLが遮断されるため、**ユーザPCで手動取得**してください。

- 取得先: `https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/18/232812/103096.jpg` など
- 必要タイル（校舎を中心に3×3）:
  ```
  z18_232811_103095.png（既存）
  z18_232812_103095.png（既存）
  z18_232811_103096.jpg ← 校舎西
  z18_232812_103096.jpg ← 校舎中央（最重要）
  z18_232813_103096.jpg ← 校舎東
  z18_232812_103097.jpg ← 校舎南（グラウンド）
  ```
- ブラウザで開いて `名前を付けて保存` → `kawaguchi_3d/` に `z18_*.jpg` として置く。Blender側ではjpg/pngどちらでも読む。
- GSI出典は `© GSI` をモデル公開時に表記。

またはBlenderGISアドオン導入後は `GIS → Web geodata → Basemap → GSI seamlessphoto` で自動取得可能。

### 2-2. Blenderでの実行

1. **継続のblendを開く**（`kawaguchi_3d.blend`）
2. `Text Editor → Open → 03_site_terrain.py → Run`
   - 何が起きるか: `10_Site_Terrain` に `TERRAIN_Flat_600m`（-0.1m, 600m四方）、`SITE_Boundary_第1校地`（敷地境界カーブ）、`SITE_River_竪川`（水面）、`SITE_Road_東/西/北`（ベベル付き道路）が生成され、校舎ブロックが `Y+12m` 北へ補正される。
3. `04_adjust_arena_to_site.py → Run`
   - 何が起きるか: アリーナS/N・プールが敷地境界に合わせて再配置される。
4. `File → Save`

### 2-3. BlenderGISでのDEM置換（任意だが推奨）

- アドオン `BlenderGIS` を `Preferences → Add-ons → Install` から導入（https://github.com/domlysz/BlenderGIS/releases）
- `GIS → Web geodata → Basemap → GSI DEM 5m` で `EPSG:6677` を選び、原点を `139.71913, 35.82613` に指定して取得。
- 取得後、既存 `TERRAIN_Flat_600m` は `H` で非表示 / または削除し、DEMメッシュを `10_Site_Terrain` に残す。
- DEMが無い間はフラットのままでもPhase2以降は進行可能（川口は平坦で高低差1m以内）。

## 補足: 今回の敷地境界トレース精度

- 印刷図のため **±1.5m** を見込む。Phase2の建物配置(±0.3m要件)には影響するが、**建物間の相対位置は27901の通り芯が優先**されるため、敷地境界の誤差は外構（植栽・フェンス）にのみ影響。
- 正確な敷地境界が必要な場合は `fgd.gsi.go.jp` の基盤地図情報「敷地境界」SHPをDLするか、法務局の公図を取得。
