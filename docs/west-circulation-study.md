# Phase 2：中央広場からラーニングストリート2Fへの正面接続・再検討

## 以前の誤りを撤回

前版では、中央広場の**南北から横向きに上がる二つの階段を2F連絡床の側面へ垂直接続**していた。ユーザーの現場の見え方に関する指摘「横からじゃなくて正面からのはず」と矛盾するため、この**直接経路としての二つの造形を削除**した。南北方向に別の外階段が実在しないという意味ではない。以前の「南北二つが直接校舎2Fに接続」とする説明・監査結果は失効する。

`27901siryou.pdf` p.3（配置）、p.4（1階）、p.5（2階）の小縮尺図は広場と外階段の手掛かりだが、外階段それぞれの接続・実寸をこの図版だけから断定できない。p.9の「2F+4.0m」は2015年**計画の階間レベル**であり、現況広場の測量GLからの高さではない。[学校の施設案内](https://kawaguchicity-hs.ed.jp/about/facility/building)により校舎棟間ラーニングストリートが2Fからの吹抜けであることを確認した。

[市の中央広場・外階段写真](https://www.city.kawaguchi.lg.jp/soshiki/01120/050/2/46357.html) の `okugaikaidann.jpg` にある赤橙色の帯・植栽島・灰色段・手摺りは実画素で確認したが、**この写真の階段が今回の正面直結階段と同一である証拠はない**。市の `tyuuouhiroba.jpg` と[JIA掲載写真](https://jia-award.jia.or.jp/kenchikusen/2023/best-architecture/2443/)には曲線状上階歩行路が見えるが、その接続断面も不明。別階段の特徴を正面直結階段へ移植しない。

## 今のモデルと検査

- `src/world/west-connection.ts`：西側中央広場から**西→東、通りの長軸に沿って正面から**上り、校舎側の2F床へ達する階段と連絡床を仮置き。既存の校舎床西端（モデルx≈5.65m）との平面重複を確保。周囲の写真由来の赤い帯・植栽島は正面階段から撤去。手摺り自体も寸法未確認の仮表示。
- 暫定輪郭：階段x=−29〜−8m、北32.5〜51.5mから北34〜50mに収束、**24段はモデル値のみ**。連絡床x=−8〜5.9m、上端モデルy=4m。すべて横方向・段数・幅・踊り場位置は非実測。モデル地面y=0は現況GLではない。
- `scripts/audit-west-connection.mjs`：メッシュへのレイで西→東に段高さが増すこと、旧側面直結階段がないこと、2F床側へ正面から届くことを回帰検査。**実測や現況一致の監査ではない**。
- 比較視点「中央広場↗2階」は校舎へ向けて階段の正面に移動。Chromium画像 `.scratch/screenshots/front-entry.png` を目視し、アリーナ壁に遮られず24段・上部踊り場と校舎への連続を確認。画面右上のFPSはヘッドレスSwiftShader値であり実機性能の保証ではない。
- 一人称開始位置も正面階段西側へ移動。操作は[`interaction-study.md`](interaction-study.md)参照。

## 残る重要な未確定

縮小平面図から踏面、正面階段の実際の位置・段数・傾斜、連絡床の境界、現況GL、写真中の他の外階段との関係を割り付けられない。湾曲した高架歩行路も未実装。**現在の一段広い直線階段を竣工実物の輪郭と誤認しないこと。** 実施詳細図・竣工時の外構平面、校舎西正面から階段全体が写る方位の分かる写真があれば、この推定を再登録する。写真と確定仕様に矛盾が判明したら拡張を止めて報告する。画像原本はアプリへ再配布していない。

## 表示ディテール追記

正面階段の24段に中性グレーの細い縁と蹴上げ影を繰返しメッシュで付加した。接続の向き、床レイ判定、段数は変えず、赤帯・植栽・架空の機器等は同定できない限り追加しない。縁の仕上げは仮表現であり竣工詳細図と照合できていない。
