## 東正面サイン壁の追加実装を中断した理由

写真で学校名サインのある端壁が右側に見える一方、現在のS棟東端に置いたサインは斜角の画面では左に出る。撮影視線を南東・北東の両方へ切り替えても位置対応が確定せず、GISの棟同定・写真の撮影方向・画像反転・サイン設置面のどれが誤りか判別できない。この状態でサイン・縦帯・外構の配置を推測だけで固定すると、ユーザーが求める写真整合と寸法精度に抵触する。**これは確定した南北反転ではなく、未解消の帰属矛盾として扱う。** 境界柵と道路も画像の存在のみ確認、平面の位置はすべて仮置き。GIS周辺建物を表示すると比較カメラが建物内部になる問題も完全には解消していない（デフォルト非表示で回避）。

なお、後続のユーザー指摘に基づくアリーナ通り側の西階段・中央広場→2Fの導線の独立した追加実装は `west-circulation-study.md` に記録。東正面の棟割矛盾は未解消のまま。

次の検証は (1) 撮影位置の判る写真または撮影方角、(2) 設計／竣工の東側立面・外構平面／配置図、(3) 階段の段数と植栽帯・GLレベル。竣工立面は公開WebとWaybackで検索済みだが発見できていない。提供前に架空寸法で穴埋めしない。

再現手順：`npm run audit && npm run build`。撮影用スクリプトは開発検証用で `.scratch/` に置いており、Chromiumの実行に一時的なNSSライブラリが必要。サイト本体は `npm run dev -- --host 0.0.0.0` で確認できる。
