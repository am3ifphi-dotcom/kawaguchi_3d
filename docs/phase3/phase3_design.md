## 3. 立面骨架（LOD3の芯）※エージェントが refs/city_pdf の平面/立面図から採寸
- **7800柱距グリッド**: S翼 109.2m = 7800×14 exactly ✓。N翼 94.6 = 7800×12 + 1000 (端柱/伸縮帯)。管理帯 103.2 = 7800×13 + 1800。
  → 柱ピッチ/柱巾は立面図から採寸（目安 C450系),階層振りは断面(S/N: 1F4.0+2-5F3.6)。
- **LCパート**: 中央テラス分割の2筏構成(S西/S東 ×(中庭テラス)) → 南側バルコニー/ルーバー帯。
- **庇/パラペット**: 軒高位置に庇オール(厚≈300推), 最高部(21.886)=パラペット頂。端部は立面の段差で読み取り。
- **開口部**: 窓ピッチ=柱距のサブグリッド(7800/3=2600 or /2)。開口率・色は写真/図面を採寸。

## 4. 手法 (Blender/ka'tsu)
- parametric 生成: masses v3 は既にリング押出h済。**Phase 3スクリプトは「立面パラメータJSON」を読み、壁面パネル/柱/窓ガラス/庇/ルーバー/パラペットをメッシュ生成**（廃止可能・再生性重視）。
- 参照: refs/city_pdf の立面/断面・p5-7平面(教室窓)。**測定はエージェント側で実施**（ページ絞込⇒pdf_render/俯瞰→市画面との対応）。
- 写真: 施設内訳 p13-14 の外観写真・地区資料(中央)の写真で色分け/開口推定（誠実タグ: 【写真推定】）。
