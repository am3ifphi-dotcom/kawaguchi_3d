# Phase 2 / 第1校地の外観スタディ（2026-09-28）

**これは竣工図を再現した完成モデルではない。** `src/world/exterior.ts` は設計図断面の数値、提供 GIS 輪郭、公開写真で見える特徴を重ねた検証用試作。1 unit = 1 m、東 X／上 Y／北 −Z。表示 y=0 は断面の 1F=0 を便宜的に置いた面であり測量 GL ではない。LOD1 校舎候補を切れば比較できる。写真のコピーは同梱しない。

## 未解決・次の検証

- 最優先：公開アーカイブでは竣工図は見つからなかった。校舎/アリーナ竣工図またはファサード立面、屋根の断面・膜骨組配置をさらに探し、GIS 投影を図面上の通り芯へ照合。現状で外形誤差 ±0.3m を保証できない。
- 東入口の実際の階段の段数と標高、基準 GL と断面 1F=0 の関係を確認。
- 学校の外壁材、外部廊下の奥行き・教室側実際の窓割、膜屋根縁の取付点、フィジカルストリートの庇、アリーナ RF 形状を確認。
- 校舎のギャラリー側は開放したが床板も屋根投影 GIS の繰返しで仮置き。精密な中空室・教室開口・衝突/重力/歩行は Phase 3 以降。今の建物内に入る運用は禁止。
- 写真は目視参照のみ。提供 PDF の再配布制約と公開写真のライセンスを確認するまで、写真の画像ファイル・生成トレースをアプリに含めない。
- 描画レイヤーのトグルで「外観スタディ」と「LOD1 校舎候補」を切り替え比較可能。重ねると同一位置のジオメトリが交差する。

## 表示確認

`npm ci && npm run audit && npm run build && npm run dev`。プレビューから校舎東側入口・斜め俯瞰・真上・北立面・南立面・アリーナ通りへ切替。`npm run build` は構文/型チェックであり目視精度や 60fps を保証しない。Chromium/SwiftShaderで7視点の実描画PNGを撮影し目視済み（`docs/screen-review.md`）。GPU実機FPSの計測ではない。

## 屋上設備・階段のディテール追加（2026-09-28）

2015年実施設計 `27901siryou.pdf` **p.7のR階平面図を実画素で拡大目視**すると、校舎北翼の膜屋根外側に「屋外機置場」1領域、南翼に同名2領域が明記され、矩形の小さい機器記号も並ぶ。ここを以前の「何もない屋上」から改善した。`src/world/roof-equipment.ts` は提供GISの校舎南北屋根輪郭の内側だけに機器をInstancedMeshで**72台仮配置**し、膜面上は配置ゼロ。ケーシング・台座・ルーバー・上面リングは演出的な展示用造形であり、**機種・台数・仕様・実際の取付位置を資料から同定したものではない**。2015年図を竣工写真と取り違えず、専用トグル「屋上設備スタディ」でOFFにできる。屋上機器を実写と照合できる現況写真は未取得。周囲のX字フレームも引き続き帰属・現況未確認。

ラーニングストリート西正面の階段は、既存の正面方向と24段のモデル床を維持しながら、縁の明度差と蹴上げの陰影をInstancedMeshで追加。写真で未同定の赤色帯・植栽島は**再追加していない**。この縁材の寸法・仕上げも仮置き。俯瞰と正面をChromiumで再撮影して段の表示を目視した。`scripts/audit-roof-equipment.mjs` で全モデル機器の学校GIS屋根内への内包、膜屋根外であることを検査するが、現況一致は証明しない。

「鑑賞モード」（Esc/Hで復帰）を追加して画面UIを一時的に消し、資料に未確定箇所があることを残すキャプションを表示。高質感ONの白飛びを抑えるためライト強度・露出を微調整。ただしヘッドレスSwiftShaderで低FPSのため実機60fps・写真級の再現は未検証。公式画像・2015PDFをアプリ内には再配布していない。
