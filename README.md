# 川口市立高等学校 3D 探検シミュレーター

埼玉県川口市上青木三丁目の「川口市立高等学校」第1校地を、WebGL / Three.js で再現した
ファンメイドの一人称ウォークスルー・シミュレーションです。

膜屋根の「ラーニングストリート」を軸に、校舎棟（S棟・N棟）・大アリーナ・中小アリーナ・
人工芝グラウンド・プール・テニスコートなどを歩き回れます。

## 起動方法

```bash
npm start          # http://localhost:8080 でサーバー起動
```

ブラウザで開き、「探索をはじめる」をクリックしてください（PC推奨: マウス＋キーボード）。

## 操作

| 操作 | キー |
|---|---|
| 移動 | W A S D（矢印キーも可） |
| 走る | Shift |
| ジャンプ | Space |
| 視点 | マウス |
| 場所移動メニュー | M |
| 時刻変更（朝/昼/夕/夜） | T |
| 飛行モード切替 | F |
| 写真モード（HUD非表示） | P |
| メニュー / カーソル解放 | Esc |

見ている場所に応じて建物の解説カード（膜屋根・都市の門・鋳物の校章など）が表示されます。
スマートフォンは仮想スティック＋ドラッグ視点に対応。

## 再現しているもの

- **校舎棟**（2021年竣工・久米設計）: S棟（HR教室）とN棟（特別教室）の間に挟まれた
  「ラーニングストリート」、2〜5Fの吹き抜け・ブリッジ・膜屋根・鋼アーチ、
  東端のガラスカーテンウォール「都市の門」と鋳物風の校章
- **内部**: 1F 大ホール（500席）・職員室・保健室、2F 食堂・ラーニングコモンズ（図書館）・
  音楽室、3F 理科実験室・コモンロビー、4F 美術室・プレゼンテーションルーム、
  3〜5F 普通教室（机・椅子・黒板・ロッカー）、各階段（実際に登れます・屋上まで）
- **アリーナ棟S**: バスケット3面・2F観客席・バナー・スコアボード
- **アリーナ棟N**: 1F 柔道場・剣道場、2F 小アリーナ
- **屋外**: 人工芝サッカーグラウンド（白線・ゴール・照明塔）、25mプール、
  テニスコート2面、弓道場、駐輪場、キャンパスロード、正門・塀、バス停「川口市立高校」、
  東側市道・信号機・街路樹、周辺街区

## 技術構成

- Three.js r186（ES modules、importmap、ビルド不要）
- ジオメトリはマテリアルごとにマージしてドローコールを削減（約180メッシュ / 約48万三角形）
- 机・椅子・座席・本棚などは InstancedMesh
- 衝突判定: AABB + 空間ハッシュ、床: 高さフィールド（階段は0.36m自動乗り上げ）
- 時間帯システム（太陽・空・霧・星を切替）、静的シャドウマップ

## テスト

```bash
npm test           # ヘッドレス統合テスト（構築 + ウォークシミュレーション）
```

canvas をスタブし Node 上でシーンを実際に構築。全テレポート地点の床の存在、
玄関→ラーニングストリート→大ホール、1F→2F→屋上の階段昇降、
グラウンド・アリーナ・プール間の移動などを自動検証します。
